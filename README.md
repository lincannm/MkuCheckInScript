本项目通过逆向 MKU 学工系统晚打卡 API，实现了：**免定位、自动化的晚打卡**。

> 思路（发布于个人博客）：https://blog.linc.work/article/dfd1638c.html

功能：

- [x] 自动打卡
- [x] 自动截取打卡记录页面

建议环境: **Python 3.12**

# 快速开始

## 安装

### 1. 安装依赖

使用 pip 从 `pyproject.toml` 安装依赖：

```shell
python -m pip install .
```

### 2. 为Playwright安装浏览器

以便打卡后自动截图

```shell
playwright install chromium
```

## 配置

首次运行会自动创建 `accounts.json` 配置文件，编辑该文件添加账号信息：

```json
{
  "accounts": [
    {
      "name": "显示名称",
      "username": "学号",
      "password": "密码"
    }
  ]
}
```

## 运行

```shell
python main.py
```

不带任何参数运行的时候，脚本会读取 `accounts.json`，并在终端中显示账号列表，要求手动输入要处理的账号序号，之后就按默认流程执行：登录账号 -> 如今日未打卡则询问确认并打卡 -> 截取打卡记录页面。

### 命令行参数


| 参数 | 说明 |
|------|------|
| `-h`, `--help` | **显示帮助。** 显示命令行帮助信息并退出，不执行账号选择、打卡或截图流程。 |
| `-m`, `--manage-account` | **管理账号。** 进入账号管理菜单，可在终端中列出、添加、编辑、删除 `accounts.json` 中的账号。使用该参数时不会执行打卡或截图流程。 |
| `-y` | **自动确认打卡。** 跳过“是否要打卡？”确认，在选中账号后直接提交打卡。仅在实际进入打卡提交步骤时生效；短信验证码等登录安全确认仍会正常询问。 |
| `-c`, `--only-checkin` | **仅打卡。** 只执行打卡流程，跳过截图步骤。若检测到今日已经打卡，则不会重复提交。 |
| `-s`, `--only-screenshot` | **仅截图。** 只截取打卡记录页面，跳过打卡步骤。仍会登录账号，以便获得截图页面所需的登录态。 |
| `-a N [N ...]`, `--accounts N [N ...]` | **指定账号。** 指定要处理的账号序号，序号从 `accounts.json` 中的账号顺序开始计数，支持一次传入多个序号，例如 `-a 1 3 5`。传入后会跳过手动选择账号。重复序号会自动去重并保留首次出现的顺序。 |
| `-o PATH`, `--output PATH` | **设置截图目录。** 指定截图保存目录，默认保存到当前用户桌面。该参数只影响截图步骤；如果使用 `-c` 跳过截图，则不会生成截图。 |
| `-d`, `--debug` | **启用调试日志。** 打印更详细的请求响应、Cookie、表单数据等信息，适合排查登录或打卡问题。注意不要把包含敏感信息的调试日志公开。 |

### 参数组合说明

- `-c` 和 `-s` 分别表示“只打卡”和“只截图”，通常不要同时使用；如果同时传入，脚本会同时跳过打卡和截图，最终只完成登录与账号处理汇总。
- `-a` 可以和 `-c`、`-s`、`-y`、`-o`、`-d` 组合使用，用于批量处理指定账号。
- `-m` 是独立的账号管理模式，传入后会直接进入菜单，不会再读取其他打卡或截图相关参数执行任务。
- `-o` 指定的目录需要提前存在；脚本会按 `screenshot_显示名称_年月日_时分秒.png` 的格式保存截图文件。

### 示例：

查看帮助：

```shell
python main.py -h
```

默认流程：选择账号、打卡并截图：

```shell
python main.py
```

进入账号管理菜单：

```shell
python main.py -m
```

仅打卡，不截图：

```shell
python main.py -c
```

仅截图，不打卡：

```shell
python main.py -s
```

选中账号后直接打卡，跳过打卡确认：

```shell
python main.py -y
```

启用调试日志：

```shell
python main.py -d
```

指定第 1 个账号打卡：
```
python main.py -a 1
```

指定第 1、3、5 个账号打卡：

```shell
python main.py -a 1 3 5
```

指定第 1、3、5 个账号直接打卡且不截图：

```shell
python main.py -a 1 3 5 -c -y
```

指定截图保存到当前目录：

```shell
python main.py -o .
```

仅为第 2 个账号截图，并保存到 screenshot 目录：

```shell
python main.py -a 2 -s -o screenshot
```
